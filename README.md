# Hill Drive

Physics hill-climb racing PWA for phones — GAS / BRAKE pedals, hills, rope bridge, coins, fuel, and boost.

## Develop

```bash
npm install
npm run dev
```

Open the local URL on your phone (same Wi‑Fi) or use browser device mode in landscape.

## Build

```bash
npm run build
npm run preview
```

## Controls

- **GAS** (right pedal / → / D) — drive forward; spin in air
- **BRAKE** (left pedal / ← / A) — reverse / slow; counter-spin in air
- **Boost** (Space / Shift) — spend boost meter
- **Pause** (❚❚ / Esc / P)
